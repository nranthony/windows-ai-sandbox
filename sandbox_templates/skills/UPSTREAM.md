# Vendored skills — what is a copy, and what this repo owns

This file is PROSE, hand-maintained. The revisions it used to pin now live in
[`../VENDORED.lock`](../VENDORED.lock), generated by `scripts/vendor-tools.sh`
from the channel manifest. Two reasons the pin moved and this text did not:

- A pin that is written by hand drifts from the thing it describes. This file
  recorded `myconv` at `e6f395d` while the vendored tree already matched
  `a934a95`, and nothing caught it — `skills-check` compared *content* and never
  the pin. `VENDORED.lock` is derived from the manifest the artifacts came from,
  so it cannot disagree with them.
- A lock file cannot carry the distinction below, which is the part a reader
  actually needs before editing anything in this directory.

## Vendored vs sandbox-native — the distinction that matters

**Vendored** skills are COPIES. Their source of truth is another repo, they
arrive through the depot channel, and **a local edit here is silently reverted
by the next `just vendor-tools`.** Edit them upstream. Currently:

| Name | Kind | Upstream | Arrives via |
|---|---|---|---|
| `myconv` | plugin | `agentic-conventions` → `plugins/myconv/` | channel (`dist/plugins/myconv`) |
| `myclickup` | skill beside a wheel | `myclickup` → `packaging/sandbox/SKILL.md` | channel (`dist/skills/myclickup`) |

`myclickup`'s skill is pair-vendored with its wheel (ADR-0006 upstream) so the
text can never describe a version the image does not have.

**Sandbox-native** skills — `audit-sandbox`, `web-read` — are owned HERE. This
repo is their source of truth, the channel never touches them, and editing them
in place is the correct thing to do.

A `plugin` entry carries `.claude-plugin/plugin.json` and loads as
`<name>@skills-dir`, so its own skills are namespaced `/<name>:<skill>`.

## Refresh

```
just vendor-tools          # consume the channel (verifies every hash first)
just tools-check           # has the channel moved ahead of VENDORED.lock?
```

Live profiles converge to this tree on their next `up` (ADR-0005). To push the
change now without touching the container:

```
scripts/profile.sh <profile> reset-skills   # converge (no backups kept)
```
